# DCTT — Dancing Tap Tile

Mobile-friendly HTML gameplay prototype. Open index.html in a modern browser.

Tap the board to aim. Hold the jump button to charge distance, then release.
Land on two matching fruit tiles to score. A center landing adds a bonus.
Desktop: aim with the mouse and hold/release Space.

This prototype is solo, with 12 pairs, session scores and restart. It has no backend, saved leaderboard or multiplayer.
